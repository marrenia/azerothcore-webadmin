Restart realm

The world exits with a restart code, so systemd brings it straight back up. Expect a couple of minutes offline while the world reloads and bots log back in.

Shut down realm

A clean shutdown exits with code 0, which systemd treats as success — so the realm stays down until you run systemctl start acore-worldserver over SSH. Use Restart above unless you mean to take it offline.
